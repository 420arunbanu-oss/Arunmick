GitHub-ல் பதிவேற்றி APK-வாக உருவாக்குவது எப்படி? (4 எளிய படிகள்)
--------------------------------------------------------------------

படி 1: இலவச GitHub கணக்கு & புதிய Repository உருவாக்குதல்
1. github.com-ல் உங்கள் கணக்கிற்கு உள்நுழையவும்.
2. "New repository" பட்டனை அழுத்தவும்.
3. Repository name-ல் "smartdrivo-free" என பெயரிடவும்.
4. "Public" என்பதை தேர்ந்தெடுத்து "Create repository" கொடுக்கவும்.

படி 2: கோட்களை GitHub-ல் ஏற்றுதல்
விருப்பம் A (GitHub இணையதளம் மூலமாக):
- உங்கள் GitHub Repository பக்கத்தில் "uploading an existing file" பட்டனை அழுத்தவும்.
- இந்த ZIP-ல் உள்ள அனைத்து கோப்புகளையும் Drag & Drop செய்து Commit செய்யவும்.

விருப்பம் B (Command Line மூலமாக):
  chmod +x push-to-github.sh
  ./push-to-github.sh https://github.com/உங்கள்_பெயர்/smartdrivo-free.git

படி 3: தானியங்கி APK உருவாக்கம் (GitHub Actions)
- நீங்கள் கோட்களை பதிவேற்றியவுடன், GitHub-ல் உள்ள "Actions" என்ற டேப்பிற்கு செல்லுங்கள்.
- "Build SmartDrivo Free APK" என்ற Workflow தானாக இயங்கத் தொடங்கும்.
- சுமார் 2 முதல் 3 நிமிடங்களில் பச்சை நிற சரி (✓) குறியீடு தோன்றும்.

படி 4: உங்கள் மொபைலில் APK டவுன்லோட் செய்து பயன்படுத்துதல்
- முடிந்த Workflow-ஐ கிளிக் செய்து, கீழ் பகுதியில் உள்ள "Artifacts" பிரிவில் 
  "SmartDrivo-OpenSource-Free-APK"-ஐ டவுன்லோட் செய்யவும்.
- அது ஒரு zip ஃபைலாக வரும், அதை unzip செய்தால் "app-debug.apk" கிடைக்கும்.
- உங்கள் ஆண்ட்ராய்டு மொபைலில் இன்ஸ்டால் செய்து கொள்ளவும்!
